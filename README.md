# 합주 전자악보

동네 아마추어 밴드가 태블릿으로 보며 함께 연주하는 전자악보입니다.
키 변경, 템포 조절, 메트로놈, 현재 마디 표시, 자동 스크롤을 큰 버튼으로 조작합니다.

- `index.html` : 앱 전체 (GitHub Pages로 그대로 서비스)
- `gas/Code.gs` : 곡을 구글 시트에 저장·공유하는 Apps Script

## 시트 연동 방법

1. 구글 시트를 새로 만든다.
2. 확장 프로그램 > Apps Script 를 열어 `Code.gs` 내용을 `gas/Code.gs` 로 교체한다.
3. 프로젝트 설정 > 스크립트 속성에 `CODE` 를 추가하고 밴드원끼리 쓸 접근 코드를 넣는다.
4. 배포 > 새 배포 > 웹 앱 (실행: 나, 액세스: 모든 사용자) 으로 배포하고 웹앱 주소를 복사한다.
5. 앱의 설정 > 밴드 공유에 웹앱 주소와 접근 코드를 입력하고 "지금 동기화"를 누른다.

Code.gs를 수정한 뒤에는 배포 > 배포 관리 > 새 버전으로 다시 배포해야 반영된다.
