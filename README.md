# 합주 전자악보

동네 아마추어 밴드가 태블릿으로 보며 함께 연주하는 전자악보입니다.
키 변경, 템포 조절, 메트로놈, 현재 마디 표시, 자동 스크롤을 큰 버튼으로 조작합니다.

- `index.html` : 앱 전체 (GitHub Pages로 그대로 서비스)
- `gas/Code.gs` : 곡을 구글 시트에 저장·공유하는 Apps Script

## 시트 연동 방법

1. 구글 시트를 새로 만든다.
2. 확장 프로그램 > Apps Script 를 열어 `Code.gs` 내용을 `gas/Code.gs` 로 교체한다.
3. 프로젝트 설정 > 스크립트 속성에 `CODE` 를 추가하고 밴드원끼리 쓸 접근 코드를 넣는다.
4. 배포 > 새 배포 > 웹 앱 (실행: 나, 액세스: 모든 사용자) 으로 배포하고 웹앱 주소를 복사한다.
5. 앱의 설정 > 밴드 공유에 웹앱 주소와 접근 코드를 입력하고 "지금 동기화"를 누른다.

Code.gs를 수정한 뒤에는 배포 > 배포 관리 > 새 버전으로 다시 배포해야 반영된다.

## 사용 설명서와 AI 검색

앱 위쪽의 `?` 버튼이 사용 설명서입니다. 질문을 적으면 설명서에서 바로 찾은 항목이 먼저 나오고,
시트 연동이 되어 있으면 Gemini가 쉬운 말로 정리한 답이 이어서 나옵니다.

- 모델은 `gemini-3.5-flash-lite` → `gemini-3.1-flash-lite` → `gemini-2.5-flash-lite` 순서로 씁니다.
- 모델별로 하루 500회를 다 쓰면(또는 구글이 한도 오류를 돌려주면) 자동으로 다음 모델로 내려갑니다.
- 하루 기준은 미국 태평양 시간 자정(한국 시간 오후 4~5시쯤)에 바뀝니다.

### Apps Script 설정

1. 프로젝트 설정 > 스크립트 속성에 `GEMINI_API_KEY` 를 추가한다. (Google AI Studio에서 발급)
2. 필요하면 `MODELS`(쉼표로 구분한 모델 이름, 앞쪽이 먼저 쓰임), `LIMIT`(모델별 하루 횟수, 기본 500)를 추가한다.
3. 편집기에서 `checkModels` 를 실행해 내 키로 쓸 수 있는 flash-lite 이름을 확인한다.
4. `testAsk` 를 실행해 권한을 승인하고 로그에 `"ok":true` 가 나오는지 본다.
5. 배포 > 배포 관리 > 연필 > 새 버전으로 다시 배포한다.
